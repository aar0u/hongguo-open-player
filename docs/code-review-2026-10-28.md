# 第一版播放器代码审查与修复（2026-10-28）

审查覆盖服务入口、下载与解密、缓存和预加载、本地数据、搜索与目录适配、Vue 播放状态、Electron 生命周期、打包配置及自动化测试。以下为代码中可复现或能由调用链直接确认的问题，均已在本次修改中处理。

| 优先级 | 问题及触发条件 | 修复 |
| --- | --- | --- |
| P1 | 视频有三个以上 CDN 候选源，前两个失败后，其他候选源从未启动，而失败计数仍等待全部候选，导致请求无法结束 | 逐步启动所有候选，失败立即尝试下一源，成功清理计时器并取消其他下载 |
| P1 | CDN 忽略分片或返回截断数据时，客户端直接拼接响应，造成损坏的 MP4 | 校验 206、Content-Range 和长度；异常回退完整下载；小文件避免无效分片 |
| P1 | 桌面版在应用源码目录存储用户记录，打包后目录可能只读，且保存失败仍返回成功 | 使用 Electron userData，支持 HONGGUO_DATA_DIR，临时文件写入后原子替换；写入成功后才更新内存，失败返回错误 |
| P1 | 打包配置包含 data/**/*，可能把开发机器的观看历史与收藏带入发布包 | 从应用打包白名单排除用户数据 |
| P1 | 任意网页可借助通配 CORS 读取本地历史、收藏、播放解析结果或触发下载 | 校验 Host、Origin 和 Sec-Fetch-Site，拒绝跨站请求；限制 JSON 请求体大小 |
| P1 | 切集、换剧时沿用旧时长、旧进度，加载期间的暂停事件可能写错观看记录 | 重置播放会话，元数据就绪前禁止保存；为视频设置独立 key，忽略旧元素事件；页面离开使用 keepalive 保存 |
| P1 | 带非法扩展 box 长度的 MP4 可在重建阶段造成不前进的循环，阻塞整个 Node 服务 | 校验 box 边界、安全整数、完整头和递归深度，重建时复用已验证的顶层 box |
| P2 | HTTP Range 不支持后缀范围，且宽松 parseInt 接受非法参数 | 支持 bytes=-N、开放结束范围，严格校验格式及安全整数，非法范围返回 416 |
| P2 | 搜索服务给两个上游传入数字，但上游要求 options 对象，因此总是第一页；App 游标未保存 | 正确传递 page，并保留有时效和数量上限的 App 分页游标 |
| P2 | 搜索下一页切回普通目录；较慢的旧列表请求覆盖新的分类或搜索结果 | 保留已提交关键词，重置搜索页码，使用请求序号丢弃过期响应；末页禁用下一页 |
| P2 | macOS 关闭窗口后重开会重复创建服务器；ready-to-show 在 loadURL 完成后才注册，可能错过显示事件 | 复用服务器启动 Promise，加载前注册窗口事件；限制窗口导航和弹出窗口 |
| P2 | 缓存只按集数限制，无法控制大视频的内存占用；HEAD 和多次 Range 请求重复创建预加载任务 | 限制缓存为 128 MiB、单次下载为 64 MiB；按 vid 和清晰度分离缓存；合并并限制预加载计时器，在当前集下载成功后启动 |
| P2 | moov 位于 mdat 之后时，重建仍扣减前面的媒体偏移，导致文件损坏 | 只修正原 moov 之后的 chunk 偏移 |
| P2 | 分类目录末页为空被当成故障；漫剧等分类故障时会显示无关的热播搜索内容 | 保留有效空页；仅综合热榜允许使用热播搜索降级，其他分类明确返回错误 |
| P2 | canplay/loadeddata 无条件恢复播放，可能覆盖用户暂停意图；无效恢复位置可残留到下一集 | 就绪事件仅更新缓冲状态；恢复位置一次性消费，恢复无效集数时选择第一集 |
| P2 | 原桌面测试强制结束所有 Electron 进程、硬编码私人路径、使用错误分集选择器且没有真正断言交互结果 | 移除全局杀进程和全桌面截图，使用独立用户目录和动态调试端口，仅清理自身实例，补充失败断言 |

## 验证

- `npm test`：14 项本地回归测试、7 项真实接口端到端用例全部通过。
- 回归测试使用本地 HTTP 夹具、临时数据目录及 Vue/Electron 边界替身，覆盖 CDN 失败、分片完整性、Range 边界、播放状态切换、过期请求、搜索游标、目录空页、原子保存、跨站访问、MP4 异常输入和布局偏移。
- 真实接口测试覆盖静态资源、目录、搜索、分集、播放解析、实际下载和解密、HEAD/Range 返回以及用户数据持久化。用户数据写入独立临时目录并在测试结束后删除。
- `node --check` 检查修改后的客户端及桌面测试脚本；`git diff --check` 通过。

## 验证边界及后续工作

- 未执行 macOS/Windows 安装包构建、安装与真实桌面播放测试。Electron 生命周期由替身回归覆盖，不能替代原生窗口及不同平台解码器的实际验证。当前环境加载 Electron 时触发二进制下载，因此未继续运行桌面测试。
- 播放代理仍在整集下载并解密后返回首字节，不是增量解密；缓存限额也不等于进程内存总上限，并发下载、解密临时缓冲仍会额外占用内存。后续可增加全局下载队列和真正的增量处理。
- 解密实现主要面向当前验证过的非分片 MP4、stco 和 8 字节 IV。co64、碎片化 MP4、其他 CENC 布局需要专用样本和回归测试后扩展。
- 上游接口不公开，成功验证代表本次运行结果，不能保证以后或不同地区的服务可用性。真实接口测试继续作为独立命令保留。
